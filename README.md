对照b站教程开发的一款全栈游戏
*视频地址：https://www.bilibili.com/video/BV1AR4y1U7xu/?spm_id_from=333.1007.top_right_bar_window_custom_collection.content.click&vd_source=2b832b8a10300fd76ab04105bbd93c80*

相较于原版进行了更好的封装并添加了详细注释，同时也配有一些点的学习记录，比较适合使用。

推荐理由：是一个非常好的入门级的全栈架构，能够快速梳理客户端和服务端在游戏开发过程中的大致流程，尤其在客户端一个项目框架大概的组成部分都有实现，在此基础上对一些模块进行替换（更好更强大的功能）是可以作为商用的，总之比市面上的一个update搞定所有的教程更适合作为入门开发基础，而且课程上使用的编程思路和代码习惯非常接近日常实际的开发工作。
